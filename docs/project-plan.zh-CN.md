## 1. 定位与当前状态

定位：可独立运行、可追溯、可复算的网络药理学分析工具，以及调用同一 CLI 的薄 Codex Skill 层。
展示重点：输入身份与分析决策可靠、统计计算可核验、Agent 能识别异常；预测关联和对接结果不构成机制或疗效验证。

截至 2026-10-26：v0.1 的 `validate → ingest → intersect → network → enrich → report → manifest`
链路已实现；包装层非零退出码、report 父链/产物哈希、富集有效前景/背景集合均有回归测试。
Linux CI 从 `renv.lock` 恢复并通过完整合成 quickstart 与正式入口合成双阈值；Windows 因 R native
exit 0xC0000005 仍有 11 个 R 相关测试失败，不能作为验证环境。真实 RA 案例已在本地 Linux Docker
完成双阈值计算与独立超几何/BH 核查；STP 表许可已确认，CTD 许可未确认，整体公开状态仍 blocked、
不得宣称公开案例通过。Skill 场景测试通过，最终版 Codex 真实会话验收已完成；后续仅增加策略边界
说明，不改分析行为，其安装版哈希与验收记录同步记录在 `docs/skill-agent-acceptance-2026-10-21.md`。
v0.0.1 是包版本/骨架标识，不能据此称为已经发布的 GitHub release；尚未打 `v0.1.0` tag。

状态统一使用：设计中 → 已实现 → 在指定环境验证 → 已发布。每项状态附 commit、运行记录或 release 链接。

## 3. 正确的数据流

```text
已确认化合物清单 ─┐
代谢组注释/筛选结果 ─┴→ 结构注册 → 性质标注 → 显式候选选择
                                             ↓
                               已下载 STP 导出 + 提交来源记录
                                             ↓
疾病基因集 + HGNC 快照 ─────────────────────→ 交集
                                             ├→ 成分—靶点—疾病网络
                                             ├→ 富集（背景、检验家族、BH 明确）
                                             └→ 可选 STRING/PPI 导入 → 拓扑/模块
前述结果 + 实验/文献证据 + 结构可用性 ───────→ 候选成分—靶点对
                                             ↓
                              受体/配体准备 → 对接 → 回对接/pose QC
                                             ↓
                                      报告 + 溯源清单
```

STRING/PPI 是交集后的可选分支，不是计算疾病交集的必要输入。
网络优先级、富集关联、对接评分分栏呈现，不混为单一“证据分数”。
外部 STP 提交仍由用户完成；已有完整导出不重复提交。离线 demo 和 CI 不依赖网站或 LLM 账户。

## 4. 上游范围与选择

支持两个入口：已确认成分清单；已处理的代谢组注释表（可附上游差异分析结果）。
首版不包含原始 LC–MS 峰提取、归一化、批次校正或模型训练；记录这些上游步骤的软件和方法来源。
导入差异结果时记录比较、重复、效应量、P/FDR 的含义；差异或高丰度不直接等于有药效。

依次完成导入、身份核验、性质标注、显式选择。Ro5、结构警示及可选 ADMET 预测是标注，
研究者可以依据预先声明的课题规则选择；全候选记录保留，选择表记录纳入/排除/待审、理由及规则版本。
未计算、无匹配、解析失败和预测阴性不是同一种状态。

质量核对明确加合物、极性、电荷、单同位素质量与 ppm 定义；容差由仪器/方法确定，10 ppm 仅可作示例。
质量或分子式吻合不能确认结构异构体。MSI 等级由实际证据支持，不由 PubChem 首条命中自动升级。
缺标准品、MS/MS 或立体证据时保留不确定性；候选集合不能强行变成单一结构。

## 5. 结构身份与跨步骤关系

| 标识/对象 | 含义 |
|---|---|
| feature_id | 原实验特征；一个化合物可对应多种加合物/多个 feature |
| compound_id | 稳定注册记录；名称、组别或文件改名不改变身份 |
| structure_id | 确定的结构表示，附立体、盐/电荷、标准化规则与版本 |
| ligand_state_id | 对接使用的质子化/互变异构状态；构象另有 conformer_id |
| submission_id | STP 实际提交结构、物种、模型/查询来源、导出文件的绑定 |
| receptor_id / pair_id | 具体受体结构及待评估的成分—蛋白对 |
| docking_run_id | 一次固定输入、状态、参数及 seed 的实际执行 |

完整映射：feature → 注册化合物 → 原始/标准化结构 → STP 实际提交结构 → 对接状态。
同一化合物的多组出现用关联表表示，不能复制成多个身份；同一 STP 任务仅在结构、物种和模型一致时复用。
标准化不静默去手性、去盐、强制中和或合并互变异构体；保留原结构和每次转换。
网络后续以带类型的稳定 ID 连接，名称只作 Label；命名空间设计须有迁移与碰撞测试。

## 6. 候选对选择

新增设计产物 candidate_pairs.tsv，先于 dock prepare。
每对记录 compound_id、structure_id、UniProt/物种、关联及疾病证据引用、选择/排除理由、
受体候选及位点依据、对照配体、准入状态和人工决定。关键字段/关联约束见 docking.md。
不得默认生成“最高 degree 的若干蛋白 × 所有成分”；可用预先声明规则提名，再结合证据与结构适配性判断。
无结构、口袋不明确、特殊化学体系等保留为不适用/待审，不从主清单无声消失。

## 7. 对接首版边界与验证

首版仅支持普通非共价小分子和适合该问题的共晶参照体系。
选择结构时检查目标/物种/链/序列覆盖、突变、寡聚体、口袋状态和实验质量；PDB 来源不自动等于适用。
记录水、金属、辅因子、替代构象、缺失区域及质子化处理。必要成分不能统一删除。
配体准备明确 pH/状态、立体、显式氢、三维构象与原子对应，保留 PDBQT 与可核验的 SDF。

盒子由共晶配体或已知位点几何计算，保存中心/尺寸/单位/算法。padding 必须定义是每侧还是总增量；
验证候选配体可容纳与搜索充分性，不设所有体系通用的 8–10 Å。
从独立生成的配体初始构象回对接，不能仅沿用晶体坐标制造容易成功的测试。

回对接约定重原子、对称性和原子映射，必要时先按受体对齐，不将配体单独拟合后掩盖错位。
分别报告 top-1 RMSD、top-k/best-sampled RMSD、采样预算和重复 seed；2 Å 是本项目预声明的常用参考判据，不等于结合确证。
pose QC 分别核查化学/几何、立体与受体碰撞；记录 PoseBusters 版本、配置、每项结果及未执行项。
回对接失败检查准备、映射、受体状态、位点、采样及评分函数，不能直接断言“盒子错”。

AlphaFold/同源模型后续作为独立适配：pLDDT 不是对接准入的充分条件，不机械删除低分区域；
同时看 PAE、位点证据和结构状态。没有原位天然参照时写 redocking_not_applicable，不伪造回对接验证。
模板配体转移属于模板/交叉对接控制，不冒充本受体天然回对接。

分数只在同受体、同准备与评分协议下作探索性比较；不将不同靶点分数直接总排，也不由分数换算实验亲和力。
回对接通过检验姿势恢复，不能证明活性排序；若声称筛选能力，另需已知活性/非活性或匹配 decoy 基准。
多 seed 的分数范围和姿势聚类用于描述搜索稳定性，不能当成独立实验重复。
不得事后挑选最佳 seed/盒子/配体状态隐藏失败；不同状态搜索预算及汇总规则提前声明。

## 8. 复现与历史迁移

每次执行保存输入/输出哈希、软件与准备工具版本、二进制哈希、完整命令、操作系统、seed、CPU、
评分函数、盒子、exhaustiveness、num_modes、energy_range、状态和原始日志。
固定 seed 不单独保证跨版本/平台逐字相同；规定受控环境重复性与数值/姿势容差，另报跨环境差异。

C:\dock 的数量和版本来自 v2/DSH 历史盘点，本次未重新核验；不能当成当前事实或已完成重构。
配置文件不含 seed/cpu 不等于运行时未设置：核查脚本、命令行和日志中的实际值。
单一工具路径可简化管理；旧目录、二进制、config 和结果先只读归档并记录哈希，不删除历史证据。
先迁移一个任务，核对来源/准备/命令/结果与新增控制，再决定批量迁移；旧结果不是新流程的独立验证。

## 9. 当前 v0.1 必须闭合的缺口

- 名单与导出明确绑定；未匹配文件隔离，不以文件名生成正式 unmapped 成分边。名称回退仅作显式兼容模式。
- STP 原始空表、无阈值内结果、非法行、部分失败分开；审计计数不将非法行记为低于阈值。
- 下游默认拒绝 incomplete/partial 上游；设计读取父阶段状态与哈希的方法，覆盖已有目录拒绝或显式处理。
- 软件代码身份与分析配置所在仓库身份分开；实际输入/参考数据及父产物哈希形成链，版本文字不替代数据绑定。
- R 背景转换失败不能静默变成默认背景；服务失败、无映射、无显著结果分开；输出完整检验表、实际背景和映射损失。
- 保留 R/clusterProfiler；合成冻结集合做独立超几何/BH 数值基准，真实 GO 契约测试另行保留。
- 明确 Python/R/注释环境；从 wheel 安装后检查 schemas、R 脚本等资源可定位，不仅在源码目录可运行。
- 一个离线合成 demo 先完整跑通；公开科学案例另建，来源及再分发许可核查后再纳入。
