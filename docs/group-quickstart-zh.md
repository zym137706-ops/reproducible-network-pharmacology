# 组内快速上手指南（v0.1.0，15–20 分钟）

> 这是给课题组同门用的试用材料，不是正式用户验证报告。
> 你不需要安装 Python/R，也不需要提交自己的课题数据。
> 如果你平时主要提需求、看结果，不亲自跑分析，也完全可以做 A 线；
> A 线就是模拟你拿到一个分析包时，怎么找输入、怎么找结果、哪里最容易看不懂。
> 按 A 线做即可；B 线只在课题组准备好的 Linux 环境里做。

## 0. 先说清楚

这次只做三件事：

1. 看一个**公开的 RA 案例包**；
2. 找出它需要哪些输入、结果在哪里；
3. 告诉我们哪一步最绕、哪句话看不懂。

没有考试，没有标准答案。找不到就写“卡在这里”，这比猜一个答案有用。

不要把自己课题的数据、未发表结果、姓名/学号/邮箱放进案例包或反馈里。

## 1. 准备（约 2 分钟）

打开 Release 页面：

https://github.com/zym137706-ops/reproducible-network-pharmacology/releases/tag/v0.1.0

下载这个文件：

`rnp-case-v0.1.0-2026-10-21.zip`

解压后应该看到一个文件夹，里面有：

```text
README.md
RESULTS-SUMMARY.md
expected/EXPECTED.json
VERIFICATION.md
inputs/
  compounds.tsv
  disease_genes.txt
  hgnc_map.tsv
  STP-SUBMISSION-LOG.tsv
  stp/
  CTD-QUERY.md
  PUBCHEM-SOURCE.md
```

如果解压后不是这些文件，先记下你实际看到的文件名，再联系组织者。

## 2. A 线：不装环境，找输入（约 5 分钟）

请打开 `inputs/`，完成下面四个小任务。可以只看文件名、用记事本或 Excel 打开，不需要运行代码。

### 任务 A1

这次分析需要哪几类输入？把对应的文件名写下来。

提示：至少看化合物、疾病基因、STP 导出、HGNC 映射、提交日志这五类。

### 任务 A2

打开 `inputs/CTD-QUERY.md`，回答：

- 疾病名是什么？
- MeSH 编号是什么？
- 用的是精确疾病词，还是包含子代疾病？
- 文件里写的 CTD 数据日期/检索日期是什么？

### 任务 A3

打开 `inputs/STP-SUBMISSION-LOG.tsv`，回答：

- 每个化合物怎样和它的 STP 导出文件对应？
- 如果只看文件名，能不能确认它对应的是哪个化合物？

### 任务 A4

打开 `inputs/PUBCHEM-SOURCE.md`，用一句话回答：

- 这些结构是“实验测定的结构”，还是“PubChem 计算描述符”？有没有第三方权利提示？

> 任务 A 只验证你能不能找到并理解输入，不代表你独立跑过分析。

## 3. A 线：不装环境，找结果（约 8 分钟）

打开 `RESULTS-SUMMARY.md`，回答下面问题。找不到就标出你卡住的位置。

1. 0.10 阈值下：
   - 交集基因数是多少？
   - 网络有多少节点、多少边？
   - 有效背景是多少？
   - GO 条目数是多少？
   - 显著条目数是多少？

2. 0.05 阈值下：
   - 交集基因数是多少？
   - 显著 GO 条目数是多少？

3. 报告里说的“条件富集”是什么意思？它能不能说明“药物一定有效”或“机制已被实验验证”？

4. 如果要确认“这次结果不是手工改出来的”，你会去看哪些文件？请写出至少两个。

5. 如果结果和上次不一样，你会先查什么？写出你的排查顺序。

### 做完再看这里

`RESULTS-SUMMARY.md` 和 `expected/EXPECTED.json` 里有冻结的预期结果。先自己找，再对照；不要一开始就抄答案。

## 4. A 线：反馈（约 3 分钟）

请用三句话告诉组织者：

1. 最卡的一步是什么？
2. 有没有哪个词/文件/数字你看不懂？
3. 如果只改一处，你最希望改哪里？

可以直接在群里发，也可以填问卷最后一题。不要发自己的课题数据。

## 5. B 线：完整跑一遍（只在准备好的 Linux 环境）

如果你的电脑没有 Python/R，**不要为了这次试用硬装**。走 A 线就够了。

如果组织者已经给你一个准备好的 Linux 测试副本，按下面的公开说明执行：

- [DATA-ACCESS.md](https://github.com/zym137706-ops/reproducible-network-pharmacology/blob/v0.1.0/examples/demo/DATA-ACCESS.md)
- 入口脚本：`scripts/case_run.py`
- 运行前确认输出目录是新的，不要覆盖冻结输入或已发布产物。
- 这条线记录为“预置环境任务测试”，不是“从零安装复现”。

Windows 原生 R 目前不是稳定支持环境；不要在 Windows 上把 R 报错当成自己的操作问题。

## 7. 一句话边界

这个案例是**预测关联和注释重叠**的演示，不是实验验证，也不是药物有效性证明。

试用反馈只用于改文档、改流程和排优先级；不能写成“用户验证了疗效”或“用户独立复现成功”。
