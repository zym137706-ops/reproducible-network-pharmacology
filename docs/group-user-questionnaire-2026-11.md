- 本组只有 5 人，问卷不记名，但无法保证绝对匿名（大家可能互相推测）。汇总只写 P1–P4 编号和角色，不引用可识别个人的原话。

- 平台可能产生访问日志；我们只使用不记名汇总，不导出个人身份字段。
- 提交即表示同意将**不记名汇总结果**用于组内讨论和产品改进；不愿意可随时退出。

## 组织者使用说明

- 发放对象：本小课题组 **5 人群**，除维护者外 **4 位同门**；暂不转发微生物大组。
- 目标回收：**3–4 份**即可做方向性判断；若少于 3 份，如实记录实际人数。**4 人不是统计样本，不计算百分比、不宣称代表性。**
- 小样本隐私：不记名但无法保证绝对匿名；只使用 P1–P4 编号和角色汇总，不引用可识别个人的原话。
- 平台建议：问卷星/腾讯问卷，关闭姓名/联系方式题项；平台自身可能记录访问日志，不导出个人字段。
- 导出后只保留不记名汇总；原始答卷、聊天记录和访谈原话留在仓库外。
- 结果记录格式：`场景 → 观察/原话 → 问题 → 优先级 → 修改/暂缓 → 复测`。
- 问卷结果与任务测试分开记录；**填了问卷不等于完成了任务测试**。
- 本轮任务以 **A 线（Windows，零安装）** 为主；不要求任何人安装 Python/R，也不安排 Linux 运行测试。
- 任务测试结果不能写成“用户独立复现成功”；A 线只是阅读/理解任务。
- 公开摘要不得包含个人身份、课题组未发表数据或可反推个人的细节。
