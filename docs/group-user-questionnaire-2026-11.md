## 组织者使用说明

- 发放对象：课题组硕士生小群；预计多数人不是分析操作者，而是需求提出者/数据提供者/结果使用者。
- 目标回收：**3–5 份**即可做方向性判断；不要用样本量宣称统计代表性。
- 平台建议：问卷星/腾讯问卷，关闭姓名/联系方式题项并尽量使用匿名设置；平台自身可能记录访问日志，不导出个人字段。
- 导出后只保留匿名汇总；原始答卷、聊天记录和访谈原话留在仓库外。
- 结果记录格式：`场景 → 观察/原话 → 问题 → 优先级 → 修改/暂缓 → 复测`。
- 问卷结果与任务测试分开记录；**填了问卷不等于完成了任务测试**。
- 任务测试结果也不能写成“用户独立复现成功”；A 线只是阅读/理解任务。
- 公开摘要不得包含个人身份、课题组未发表数据或可反推个人的细节。
