# 问卷星导入说明（本组 5 人问卷）

模板文件：

[group-questionnaire-wjx-import.txt](group-questionnaire-wjx-import.txt)

这是按问卷星“从文本创建问卷”格式整理的**纯文本导入稿**，不是 Markdown 问卷。标题、题目、选项和题型都已按官方文本格式排列。

## 1. 导入路径

1. 登录问卷星，选择 **创建问卷 → 调查**（不要选“考试”）。
2. 选择 **从文本创建问卷 / 导入文本**。
3. 打开 `group-questionnaire-wjx-import.txt`，全选、复制、粘贴到文本框。
4. 先点预览，确认题型和选项没有错位，再保存。

官方入口说明：[从文本创建问卷](https://www.wjx.cn/help/help.aspx?helpid=138&h=1)

## 2. 导入后必须检查

- [ ] 标题为“**小课题组网络药理学/多组学分析需求与结果使用问卷**”。
- [ ] 第 1、3、4、7、8、9、12 题是**多选题**。
- [ ] 第 19、20 题是**填空题**。
- [ ] 其余为单选题；第 6、11 题含“没遇到过/不适用”，不需要设置跳题逻辑。
- [ ] 所有题目设置为**非必答**（小样本、自愿填写；不要强迫 4 位同门全部作答）。
- [ ] 不添加姓名、学号、手机号、邮箱、身份证等字段。
- [ ] 问卷说明保留“只有 5 人、不能保证绝对匿名、只做 P1–P4 汇总”的表述。
- [ ] 发布前自己用手机预览一遍，确认选项没有乱码。

## 3. 平台设置建议

- 问卷类型选“调查”，不要选“考试”，否则会要求正确答案。
- 不开启“抽奖/红包”等诱导分享。
- 不收集联系方式；愿意参加任务的人在群里单独联系。
- 若平台默认记录 IP 或微信信息，不导出这些字段，也不在汇总里写。
- 小群发放，不转发微生物大组；链接只发本组 5 人群。

## 4. 发布后的群发文案

可以直接使用问卷 Markdown 文件里的“发到本组 5 人小群的文案”，把问卷星生成的链接替换掉 `[在这里放问卷星/腾讯问卷链接]`。

## 5. 与原 Markdown 问卷的对应

为适应问卷星文本导入、不设置跳题逻辑，模板做了两处拆分：

- 原第 5 题拆成 **Q5（是否遇到过）+ Q6（原因，含“没遇到过/不适用”）**；
- 原“结果看不懂”与“最卡的类型”拆成 **Q10 + Q11（含“没有遇到过/不适用”）**。

因此导入稿共 **20 题**，原 Markdown 为 18 题；内容没有增加新的研究问题。

## 6. 不要做的事

- 不要因为只有 4 位同门就补造答卷、凑百分比。
- 不要把 Q19/Q20 的开放回答原文直接公开；只做脱敏摘要。
- 不要把问卷结果写成“代表性用户调研”或“独立复现验证”。
- 不要在导入后保留 Markdown 的 `[ ]` 复选框；文本模板已经改成选项 A/B/C。
